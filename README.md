# 📋 My Tasks - 나만의 미니멀 Todo List

> **Notion 감성의 깔끔한 UI와 직관적인 반응형 대시보드를 제공하는 브라우저 기반 개인용 할 일 관리 웹 애플리케이션**

별도의 설치나 서버, 회원가입 없이 브라우저에서 바로 실행할 수 있는 가볍고 직관적인 순수 웹 애플리케이션입니다.  
데스크톱에서는 시원한 2컬럼 대시보드로, 모바일에서는 터치에 최적화된 1컬럼 레이아웃으로 하루 10~20개의 할 일을 스마트하게 관리해보세요.

---

## ✨ 주요 기능

### 1. 3가지 카테고리 관리 & 고유 색상 태그
- **업무 (`work`)**: 파란색 (`#4A90E2`)
- **개인 (`personal`)**: 초록색 (`#27AE60`)
- **공부 (`study`)**: 보라색 (`#8E44AD`)
- 할 일 추가 시 원하는 카테고리를 선택할 수 있으며, 목록에서 시각적인 컬러 태그로 구분됩니다.

### 2. 스마트 카테고리 필터 & 실시간 카운트
- **전체 / 업무 / 개인 / 공부** 탭을 클릭하여 원하는 카테고리만 한눈에 필터링
- 각 카테고리별 등록된 건수 뱃지가 실시간으로 계산되어 표시됩니다.

### 3. 실시간 진행률 대시보드
- 현재 완료된 할 일 건수와 전체 건수, 그리고 **달성률(%)**을 큼직한 수치로 제공
- 부드러운 애니메이션의 프로그레스 게이지 바로 오늘의 성취도를 시각적으로 확인

### 4. 상대 시간 표시 (Time Ago)
- 각 할 일 항목마다 `"방금 전"`, `"15분 전"`, `"2시간 전"`, `"1일 전"` 등 생성 시점을 직관적으로 표시
- 페이지 새로고침 없이 1분마다 자동으로 최신 시간으로 업데이트됩니다.

### 5. 완벽한 반응형 웹 디자인
- **데스크톱 (와이드 화면)**: 좌측 사이드바(헤더, 진행 현황, 카테고리 필터) + 우측 메인 영역(입력 폼, 할 일 목록)의 2컬럼 대시보드
- **모바일 & 태블릿**: 좁은 화면에 맞춰 1컬럼 수직 스택 및 2x2 필터 타일 그리드로 깔끔하게 자동 전환

### 6. 자동 데이터 저장 (LocalStorage)
- 추가, 수정, 삭제, 완료 상태가 브라우저의 `LocalStorage`에 즉시 저장되어 새로고침하거나 브라우저를 닫았다 열어도 데이터가 안전하게 유지됩니다.

## 🚀 빠른 시작 (Quick Start)

Node.js, npm, 서버 등의 복잡한 설치나 빌드 과정이 전혀 필요하지 않습니다.

1. 본 프로젝트 폴더를 엽니다.
2. `todo-app/index.html` 파일을 더블클릭하여 사용하는 웹 브라우저(Chrome, Edge, Safari, Firefox 등)로 실행합니다.
3. 바로 새로운 할 일을 등록하고 사용할 수 있습니다!

```

│       ├── app.js             # 애플리케이션 진입점 및 컨트롤러
```

## 🛠️ 기술 스택

- **언어**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **프레임워크/라이브러리**: 없음 (Pure Vanilla JS)
- **저장소**: Browser LocalStorage
- **폰트**: OS 시스템 고딕 폰트 (`-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Noto Sans KR` 등)
- **외부 종속성**: 0개 (외부 CDN, 패키지 의존성 없음)

---

## 💡 주요 단축키 및 팁

- 할 일 입력 후 **`Enter`** 키를 누르면 바로 등록됩니다.
- 할 일 내용이나 체크박스를 클릭하여 간편하게 완료/미완료를 전환할 수 있습니다.
- 할 일 카드의 **`수정`** 버튼을 누르면 즉시 내용을 변경할 수 있습니다.
- 브라우저를 닫아도 로컬스토리지에 저장되어 언제든지 다시 이어서 관리할 수 있습니다.
